# Biblioteca NG — infraestrutura básica

18 símbolos genéricos originais e editáveis para explicações técnicas: celular, tablet, roteador Wi-Fi, servidor, notebook, computador, cloud, banco de dados, usuário, pasta, impressora, switch, rede, firewall, proteção, alerta, calendário e backup.

## Importar

Baixe `ng-infra-basica.excalidrawlib`. No Excalidraw, abra Biblioteca e use a opção de carregar/importar biblioteca do arquivo. Arraste os itens para o desenho. Os itens são grupos de formas nativas, não imagens rasterizadas; é possível desagrupar e editar.

## Estado

Pacote inicial, sem integração automática à interface e sem implantação. JSON, identificadores únicos e presença de elementos validados; teste de importação e revisão na interface ainda pendentes. Não representa o catálogo completo solicitado.

## Expansão planejada

Bibliotecas separadas: Azure, AWS, Google Cloud, Microsoft 365, Dell, bancos de dados e redes. Usar ícones oficiais sem redesenhar marcas e documentar termos de cada conjunto. Os termos desses ícones não são automaticamente MIT por estarem em um fork MIT. Nenhum logotipo de fornecedor está incluído neste pacote.
